# Project Support & Help

Welcome to support for the Azure SOC L2 Cyber Range with Terraform! Below are the recommended channels for getting assistance and resolving questions.

---

## Self-Service Resources

Before opening a question or issue, please check the following resources:

1. **[README.md](README.md)**: Comprehensive lab documentation, prerequisites, network topology, step-by-step deployment, and verification queries.
2. **[terraform.tfvars.example](terraform.tfvars.example)**: Input variable template showing required and optional settings.
3. **[docs/Sentinel-Coverage-and-Testing.md](docs/Sentinel-Coverage-and-Testing.md)** and **[Ansible/README.md](Ansible/README.md)**: Detailed coverage, controlled test catalog, and guest service automation guides.

## Recommended Channels

### 1. Conceptual Questions & General Help
If you have questions about how Microsoft Sentinel works, log collection via AMA/DCR, or how to adapt analytic rules:
- Search or start a thread in the repository's **GitHub Discussions** tab.
- Check previously answered discussions first.

### 2. Technical Issues & Bugs
If you have identified a clear bug in the Terraform or Ansible code (e.g., provider schema error, broken resource dependency):
- Search **existing GitHub Issues** (both open and closed) to see if it has already been reported.
- If not, open a new issue using the [Bug Report template](.github/ISSUE_TEMPLATE/bug_report.yml).

### 3. Feature & Detection Requests
If you would like to propose a new analytic rule, data connector, notebook, or playbook:
- Open a proposal using the [Feature Request template](.github/ISSUE_TEMPLATE/feature_request.yml).

### 4. Security Matters
- See [SECURITY.md](SECURITY.md) for private, confidential vulnerability reporting.
